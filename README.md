# HR-Analytics-Dashboard

Project Overview

An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and understand workforce trends. The dashboard helps visualize key HR metrics and supports data-driven decision-making.

Tools & Technologies

- Microsoft Power BI
- Microsoft Excel / CSV
- Data Analysis
- Data Visualization

Project Objectives

- Analyze employee headcount.
- Understand employee attrition trends.
- Examine department-wise employee distribution.
- Analyze employee demographics.
- Identify patterns in workforce data.

Dashboard Features

- Interactive HR dashboard
- Employee count and attrition analysis
- Department-wise analysis
- Employee demographics
- Visual reports and charts

Project Files

- Power BI Dashboard (.pbix)
- HR Analytics Dataset (.csv)

Key Learnings

- Data cleaning and data preparation
- Creating interactive dashboards
- Data visualization using Power BI
- Analyzing HR metrics
- Presenting business insights through reports
